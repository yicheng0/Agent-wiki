我发现大多数人获取热点的方式都太低效了。  
  
刷微博、刷知乎、刷X、刷B站……  
一天花几个小时，却不知道真正重要的事情发生了什么。  
后来我把工具精简到了 13 个：  
  
① NewsNow  
全网热榜聚合，一页看完微博、知乎、B站、V2EX  
[github.com/ourongxing/newsnow](https://github.com/ourongxing/newsnow)  
  
② 今日热榜  
收录最全的中文热榜导航  
[tophub.today](https://tophub.today)  
  
③ SoPilot  
专门追踪 X 上的爆款推文和热门讨论  
[sopilot.net](https://sopilot.net)  
  
④ DailyBrief  
AI 自动生成每日科技与 AI 简报  
[github.com/leiting-eric/DailyBrief](https://github.com/leiting-eric/DailyBrief)  
  
⑤ Trends Hub  
聚合国内外数十个平台热榜，支持 API 和 MCP  
[github.com/bytesfly/trends-hub](https://github.com/bytesfly/trends-hub)  
  
⑥ RSSHub  
把几乎任何网站变成 RSS 信息源  
[github.com/DIYgod/RSSHub](https://github.com/DIYgod/RSSHub)  
  
⑦ FreshRSS  
最强开源 RSS 阅读器之一，自建信息中心必备  
[github.com/FreshRSS/FreshRSS](https://github.com/FreshRSS/FreshRSS)  
  
⑧ awesome-ai-news  
收录 AI 新闻、资讯和聚合工具大全  
[github.com/taielab/awesome-ai-news](https://github.com/taielab/awesome-ai-news)  
  
⑨ ReadYou  
颜值很高的开源 RSS 阅读器  
[github.com/Ashinch/ReadYou](https://github.com/Ashinch/ReadYou)  
  
⑩ Glance  
打造属于自己的热点监控仪表盘  
[github.com/glanceapp/glance](https://github.com/glanceapp/glance)  
  
⑪ Hacker News  
全球开发者每天都在看的技术新闻源  
[github.com/HackerNews/API](https://github.com/HackerNews/API)  
  
⑫ Lobsters  
高质量程序员社区，信噪比远高于大部分论坛  
[github.com/lobsters/lobsters](https://github.com/lobsters/lobsters)  
  
⑬ GitHub Trending  
发现正在爆发的新项目和技术趋势  
[github.com/trending](https://github.com/trending)  
  
现在每天早上花 5 分钟：  
✅ 知道 AI 圈发生了什么  
✅ 知道 GitHub 在火什么项目  
✅ 知道 X 上在讨论什么  
✅ 知道产品圈和开发者圈的新趋势  
信息差的本质，不是知道得更多。  
  
而是更早知道重要的事。  
收藏备用。
